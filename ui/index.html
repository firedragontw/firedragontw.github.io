快速開始

新頁面從這段開始

把這段貼進新頁面就有底色、字體、亮暗模式和 focus 樣式。想換色就把 fd-mood-neon 換成別的情緒。

<!-- head -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@500;600&family=Noto+Sans+TC:wght@400;500;700;900&family=Noto+Serif+TC:wght@600;700&display=swap">
<link rel="stylesheet" href="/firedragon-ui.css">
<!-- 先套用記住的主題，避免暗色模式閃一下 -->
<script>try{var t=localStorage.getItem('fd-theme');if(t==='light'||t==='dark')document.documentElement.setAttribute('data-theme',t);}catch(e){}</script>

<!-- body：結構不變，只換情緒 -->
<body class="fd-base fd-mood-neon">
  <section class="fd-card">
    <span class="fd-badge">判斷位數</span>
    <div class="fd-readout">0.00340</div>
    <input class="fd-input fd-mono" id="answer" placeholder="輸入答案">
    <button class="fd-btn">送出</button>
  </section>
</body>

給 Claude 和代理人的規則

  • 只用 token。顏色寫 var(--primary)，不寫 hex，換情緒和暗色才會跟著變。
  • 情緒放在 body。一頁一個 .fd-mood-*，不要在元件上各自加。
  • 白字只放在 --grad-fill 或 --primary 上。壓在漸層上時加 text-shadow: var(--on-grad-shadow)，亮青那端才讀得到。
  • 可點的東西至少 44px 高，而且要有 :focus-visible 樣式。
  • 動畫都要尊重 prefers-reduced-motion，關掉時內容要完整可見。
  • 不要全域改寫 .fd-card、.fd-tile。要特效就加 .fd-beam、.fd-glass 這類修飾 class。

陰影說「這是物件」，光暈說「你正在碰它」

v2 改了什麼
  1. 亮色的 --ink-3 加深，提示文字和標籤從 3.3:1 提高到 5:1 以上。
  2. 暗色底更深、卡片和底拉開層次，主色換回比較電的藍 #5b82ff。
  3. 新增 --grad-fill（主色到青色，保留 v1 的藍色漸層）：磁磚 hover、翻轉卡背面、首頁連結 hover 共用它；新增 --on-grad-shadow 讓白字在亮青那端也看得到。
  4. focus 環改成兩圈加一點光暈，鍵盤操作時一定看得到。
  5. 輸入框邊線、標籤文字、答對答錯按鈕的文字色都改成過 AA 的版本。
  6. 暗色模式下櫻粉、紫羅蘭會自動提亮；新增情緒「橘焰」。
  7. 新增選用特效：.fd-beam、.fd-spot、.fd-btn-neon、.fd-card.fd-glass。
  8. 修好首頁在「系統暗色」時極光被調暗的問題。
